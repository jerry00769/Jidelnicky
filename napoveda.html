1. Začínáme

Po dokončení počáteční synchronizace s GitHubem aplikace nabídne přechod na aktuální týden, pokud pracovní týden neodpovídá dnešku; původní rozpracovaný jídelníček zůstane zachován, pokud nabídku odmítneš. Pondělní Oběd 1 se střídá podle posledního dřívějšího schváleného pondělí: po rybě luštěniny, po luštěninách ryba. Pondělí bez vaření a pondělí s jinou kategorií se přeskakují. Pokud takové pondělí v historii není, začínají luštěniny. Při ruční změně lze vědomě potvrdit výjimku a při schvalování týdne se na ni aplikace zeptá znovu. Datum týdne vybírej ve stejném barevném kalendáři jako při kopírování historie: zeleně je dnešek, modře vybraný den a světle modře pracovní týden. Přechod na jiný týden vyžaduje potvrzení a lze jej vrátit tlačítkem Zpět. Vyber počet obědů (1 nebo 2) a dny vaření. Tlačítkem Generuj další připrav nový návrh. Kliknutím na polévku nebo hlavní jídlo lze pokrm změnit. Schválit a uložit přidá hotový týden do historie. Při opětovném schválení stejného týdne se aplikace zeptá, zda přepsat původní verzi.

2. Historie – prohlížení a práce s uloženými týdny

Stiskni Historie v horní liště nebo Prohlížet a spravovat historii v pravém panelu. Vlevo vyber uložený týden, vpravo se zobrazí celý jídelníček včetně polévky, Oběda 1, případného Oběda 2 a nevařících dnů. Týdny jsou seřazeny od nejnovějšího; klepnutím na datum zobrazíte celý jídelníček.

Načíst jídelníček otevře pracovní kopii v hlavním jídelníčku. Kopírovat do jiného týdne otevře kalendář. Dnešní den je zeleně, vybraný den modře a cílový pracovní týden světle modře. Tlačítko Dnes vrátí kalendář na aktuální datum. Kopie je pouze pracovní návrh, schválená historie se nemění. Tisk / PDF vytiskne zvolený týden. Smazat z historie odstraní týden po potvrzení; tlačítko Zpět umí změnu v běžící relaci vrátit.

3. Import historie z původního Python programu

V pravém panelu vyber Import historie z Pythonu a otevři původní soubor historie_jidelnicku.json. Import doplní týdny, které ještě v prohlížeči nejsou, a zachová již existující týdny. Po importu se změny mohou automaticky synchronizovat na GitHub, je-li připojen. Před importem doporučujeme Export JSON jako zálohu.

Přenos historie mezi Pythonem a WEBem: V obou aplikacích použij Export historie a Import historie. Soubor JSON obsahuje pouze seznam uložených týdnů, nikoli katalog nebo nastavení. Při importu volba Ano nahradí celou historii, Ne nic nemění. Před přepsáním WEB uloží původní historii do prohlížeče a nabídne její stažení; Python vytvoří zálohu na disku. Kompletní Export JSON / Import JSON je samostatná funkce pro zálohu všech WEB dat. GitHub synchronizuje změněnou historii společně s ostatními daty.

4. Úpravy jídel a dnů

V hlavním náhledu klikni na název jídla, vyhledej nové jídlo a vyber ho. Vypnutý den se označí „(nevaří se)“. V databázi i ve výběru pokrmů je výchozí filtr VŠECHNY, který ukazuje všechny kategorie abecedně. Konkrétní kategorii lze zvolit pro zúžení seznamu. Při výběru pokrmu je aktuální jídlo zvýrazněné. Nové jídlo lze přidat pouze do konkrétní kategorie; přejmenování a smazání funguje i při filtru VŠECHNY. Hledej i bez diakritiky, kliknutím vyber jídlo, které můžeš přejmenovat nebo smazat. Nové jídlo napiš do pole a klikni Přidat. Přejmenování položky v katalogu upraví i aktuální pracovní jídelníček; již schválená historie se kvůli věrnosti archivu nemění. Změny lze vracet tlačítkem Zpět. Tlačítka Zpět / Znovu vracejí změny v aktuální relaci.

5. Pravidla jídelny

V pravém panelu nastav minimální počty ryb, luštěnin a bezmasých jídel, maximální počet sladkých jídel a zakázané kombinace. Vlastní pravidla se zadávají po řádcích, například ZAKAZ_HLAVNI = smažený sýr nebo ZAKAZ_KOMBINACE = hrachová | čočka. Stiskni Uložit pravidla. Kontrola pravidel vyhodnocuje aktuální návrh.

6. Učení preferencí jídel

Web si při ruční výměně zapamatuje preferenci nového jídla a mírně sníží preferenci nahrazeného jídla. Sleduje také kombinace polévky s Obědem 1 i Obědem 2. Při dalším generování pak upřednostňuje oblíbené pokrmy pravděpodobnostně, nikoli povinně. Pravidla jídelny, střídání pondělí a zákaz opakování mají vždy přednost. Učení se ukládá do společných dat přes GitHub, pokud je synchronizace připojená. Starší zálohy bez učení se načtou s prázdnými preferencemi. Učení není automaticky sdílené s desktopovým Pythonem, který má vlastní soubor preferencí.

7. Ukládání a zálohy

Důležité: Aplikace ukládá data lokálně do prohlížeče. Při připojení GitHubu se navíc sdílejí přes soubor spolecna_data.json. Při souběžných úpravách na více zařízeních může vzniknout konflikt. V Nastavení je v takovém případě tlačítko Vyřešit konflikt; nejprve stáhne místní zálohu a teprve po dalším potvrzení převezme společná data. Vymazáním dat prohlížeče bez zálohy můžeš přijít o neodeslané změny.

Export JSON uloží katalog, historii, nastavení i pracovní týden. Import JSON obnoví celou takovou zálohu a po potvrzení nahradí aktuální lokální data. Import historie naopak historii pouze doplňuje: stejné týdny podle data ponechá beze změny, přidá pouze chybějící. Soubor historie_jidelnicku.json se zkopírováním do složky webu sám nenačte. Před importem doporučujeme Export JSON.

8. GitHub a synchronizace mezi zařízeními

V Nastavení lze připojit GitHub pomocí přístupového tokenu, načíst společná data, vyřešit konflikt a odpojit synchronizaci. Token se pamatuje v místním úložišti konkrétního prohlížeče. Změny se nejprve ukládají lokálně a po připojení se synchronizují přes spolecna_data.json v repozitáři.

Po návratu na web se kontrolují nová společná data. Při rozdílných neodeslaných úpravách se místní změny nemají bez potvrzení přepsat. Před řešením konfliktu nebo obnovením zálohy použij Export JSON. Offline soubor otevřený přes file:// a online web mají oddělené místní úložiště, takže pouhé zkopírování souborů nepřenese aktuální historii.

9. Mobilní a tabletové ovládání

Na menších displejích jsou některé akce pod nabídkou ☰ Další. Po výběru akce se nabídka zavře. Hodnoty Neopakovat hlavní a Neopakovat polévky se na mobilu a tabletu vybírají z rozbalovacích seznamů, na počítači se zadávají číslem. Kliknutí na datum otevře kalendář; vybraný den určí pondělí příslušného týdne.

10. Tisk a PDF

Tisk / PDF otevře dialog prohlížeče. Ve Windows vyber „Microsoft Print to PDF“ nebo „Uložit jako PDF“. CSV lze otevřít v Excelu.
